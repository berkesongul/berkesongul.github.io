## 👨‍💻 About The Project

This is my personal portfolio website, designed with a **modern glassmorphic aesthetic**. It showcases my projects, skills, and experience as a **Software Developer & Physics Student** at Dokuz Eylül University. While coding the future, I try to discover the fundamental laws of the computer and the universe.

> "Coding the future, discovering the universe."

### ⚡ Features
- **Premium Glassmorphic Design:** Sleek, modern UI with subtle glow and spotlight effects.
- **Interactive 3D Profile Card:** Smooth mouse-tracking tilt effects for an engaging user experience.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewports.
- **Fast & Modern:** Built with React + Vite + Tailwind CSS for lightning-fast performance and clean styles.

## 🛠️ Tech Stack

- **Core:** React (JSX), Vite, JavaScript (ES6+)
- **Styling:** Tailwind CSS, Custom CSS (Glassmorphism & Tilt effects)
- **Icons:** Lucide React
- **Animations:** Framer Motion

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/berkesongul/berkesongul.github.io.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
